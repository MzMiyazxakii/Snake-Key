# Snake Key — Minecraft Forge 1.20.1

Небольшой клиентский мод: нажми **K** в игре, чтобы открыть окно «Змейка».

## Управление
- Стрелки или WASD — движение.
- Esc — закрыть окно.
- R — начать заново после проигрыша.

## Сборка
Нужны JDK 17 и Gradle 8.8:
```bash
gradle build
```
Готовый мод появится в `build/libs/`.

GitHub Actions автоматически собирает мод при каждом push. Открой вкладку Actions, выбери завершённый запуск workflow и скачай artifact `SnakeKey-Forge-1.20.1`. Внутри будет JAR.

Требуются Minecraft **1.20.1**, Forge **47.4.28** и Java **17**.
